# AlgoSensei 

## Personalized DSA Complexity & Pattern Assistant

AlgoSensei is an AI-powered learning platform designed to help students improve their Data Structures and Algorithms (DSA) skills through intelligent pattern recognition, complexity analysis, and personalized recommendations.

Unlike traditional coding platforms that provide direct solutions, AlgoSensei focuses on strengthening analytical thinking by identifying algorithmic patterns, explaining complexity reasoning, and guiding users toward better problem-solving approaches.

---

## 📖 Overview

Data Structures and Algorithms form the foundation of software development and technical interview preparation. Existing coding platforms provide large problem repositories but often lack personalized guidance and structured learning support.

AlgoSensei bridges this gap by acting as an intelligent learning assistant that helps users:

* Identify algorithmic patterns
* Analyze time and space complexity
* Optimize solutions
* Track learning progress
* Receive personalized problem recommendations

---

## ✨ Features

### 🔍 Pattern Recognition

Identifies the underlying algorithmic pattern used in submitted solutions.

Examples:

* Sliding Window
* Two Pointers
* Binary Search
* Dynamic Programming
* Greedy Algorithms
* Graph Traversal

### ⚡ Complexity Analysis

Provides detailed:

* Time Complexity Analysis
* Space Complexity Analysis
* Step-by-Step Reasoning

### 🧠 Solution Optimization

Analyzes inefficient approaches and suggests optimized solutions.

### 📚 Personalized Recommendations

Recommends the next set of problems based on:

* Learning history
* Solved patterns
* Difficulty progression

### 💾 Progress Tracking

Stores analyzed problems with metadata and pattern information to support long-term learning.

### 🤖 AI-Powered Guidance

Encourages analytical thinking by providing explanations and guidance rather than directly revealing answers.

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/<your-username>/AlgoSensei.git
```

### Navigate to the Project Directory

```bash
cd AlgoSensei
```

### Install Dependencies

```bash
npm install
```

### Run the Application

```bash
npm start
```
